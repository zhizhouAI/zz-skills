# zz-rival-file · 同行档案

## 一句话
挑 3~5 个同行，拆到能直接抄的程度。

## 用与不用

适合用：

- 新进一个行业，不知道获客和成交该怎么做，需要一份能对照的参照
- 自己的做法增长停滞，想看看同行最近在用什么新办法
- 准备改定价、改套餐或上新服务，想知道别人怎么定、怎么卖
- 要向老板或投资人讲清竞争格局，需要一份拿得出手的说明
- 看到同行突然起量，想知道是真本事还是赶上风口

不该用：

- 想原样复制别人整个模式、不做任何适配——档案只负责标「能抄 / 抄不动」，适配自己负责
- 行业里总共只有两三家玩家，样本不够，不如逐家深聊
- 想靠爬隐私数据、混群偷聊天记录来监控对手——不做，只用公开可核对的信息
- 刚跟同行吵完架、想证明「他们不过如此」——带着情绪找证据，档案会失真

## 开工前要什么

必需：

- 你自己生意的一句话定位（对标得有锚点）
- 行业或品类关键词（用来找同行）
- 这次最想解决的问题：获客、转化还是交付
- 你能投入做对标的天数（决定拆几家、拆多深）

可选：

- 你已经知道的几个同行名字
- 你的预算和团队人数（判断抄不抄得动用）
- 你能接受的合规边界（比如能不能做电话销售、能不能承诺效果）
- 你所在客群的地域范围（线上线下打法差异很大）

用户没给时的默认假设：

- 没给同行名单，就按品类关键词加客单价区间筛，以「规模略大于你」的为主
- 没说预算，按「3 人以内小团队、月推广预算 2 万以内」评估可抄性
- 公开信息拿不全时，写「看起来是……」并标推测，不编数字
- 同行数据实在找不到，就只做动作拆解、不做数据对比，档案里写明「数据缺失」

## 怎么做

全文沿用同一个例子：林姐的少儿乐高编程课（线上录播加社群，客单价 999 元，月成交约 40 单，口碑不差但增长停了）。她最想解决获客。

1. **定筛选标准。**
   - 做什么：从客单价、目标客户、规模三个维度定「值得学」的线，最多三条。
   - 判断标准：每条都和你自己的生意直接可比；超过三条就砍。
   - 中间产物：筛选标准卡。
   - 示例：林姐定了三条：客单价 500~2000、面向家长、规模是她 5~10 倍。

2. **筛出 3~5 家。**
   - 做什么：用关键词搜索、平台榜单、行业社群收集候选，按标准砍到 3~5 家。
   - 判断标准：名单里至少 1 家规模明显大过你（看天花板），至少 1 家和你体量相近（看可行性）。
   - 中间产物：同行名单，每家附一句入选理由。
   - 示例：筛出 3 家——A：抖音矩阵号，主号 12 万粉；B：宝妈分销，约 3000 个分销妈妈；C：线下机构转线上，80 个校区。

3. **逐家拆获客。**
   - 做什么：看对方流量从哪来：平台账号、投放、分销、线下，逐个记下来。
   - 判断标准：每家至少找到 2 个可观察的获客动作，能给出账号名、链接或截图描述。
   - 中间产物：获客拆解表（渠道 / 动作 / 证据）。
   - 示例：问林姐平时刷到过 A 家什么。她发来 3 条链接：9 个抖音号每天共发十几条「孩子作品前后对比」视频，评论区引导私信领体验课；B 家靠妈妈晒娃返现 50 元，分销后台截图为证。

4. **逐家拆转化。**
   - 做什么：自己走一遍对方的成交路径，从看到内容到付款，记下页面、话术、报价方式。
   - 判断标准：能写出从「陌生」到「付款」的完整路径，不超过 6 步；写不出就换个号再走一遍。
   - 中间产物：转化路径图，每家一条。
   - 示例：A 家 4 步：刷到视频 → 私信领免费体验课 → 1 对 1 测评 → 999 正课。C 家 3 步：到店测评 → 家长会 → 5800 年课。

5. **逐家拆交付。**
   - 做什么：看买完之后对方给什么：服务流程、交付物、售后、社群。
   - 判断标准：能说出对方交付里最重的一环，以及那一环大概几个人在干。
   - 中间产物：交付拆解表。
   - 示例：A 家录播加每周直播答疑，2 个全职老师服务 600 学员；C 家人工批改加线下赛事，40 多个兼职老师，交付很重。

6. **逐项打标：能抄 / 抄不动 / 别抄。**
   - 做什么：把拆出来的动作逐条归三档。能抄：预算人力够、也合规；抄不动：缺资源或缺能力；别抄：跟定位冲突，或已被平台打压。
   - 判断标准：三档都得有内容；「能抄」每条写清第一步怎么开始。
   - 中间产物：可抄清单，含第一步。
   - 示例：A 的作品对比视频能抄——一部手机拍自家学员就能拍；A 的 9 号矩阵抄不动——缺 3 个运营人力；C 的线下赛事别抄——和录播定位冲突。

7. **汇总成档案。**
   - 做什么：按模板合成档案，每家一页，末尾写「我的三步行动」。
   - 判断标准：给一个不了解项目的同事看，他能复述每家怎么赚钱、你打算先抄哪步。
   - 中间产物：同行档案全稿。
   - 示例：林姐的三步——第一周拍 10 条学员作品对比视频；第二周把私信话术改成「免费领测评」；第三周上线 9.9 元体验课承接。

8. **一周后回访校准。**
   - 做什么：把「能抄」里已经动手的项跑一周后回看，逐条记录带来了什么变化。
   - 判断标准：每条写「有效 / 无效 / 待定」三选一，无效的附一句原因；不许全标有效。
   - 中间产物：校准记录。
   - 示例：林姐一周后回看：作品对比视频带来 47 个私信——有效；9.9 元体验课只卖出 3 份——待定，先改定价页文案再观察一周。

## 交付长什么样

```
# 同行档案：<你的生意> × <行业/品类>
日期：YYYY-MM-DD    筛选标准：<不超过 3 条>

## 同行名单（3~5 家）
| 同行 | 一句话定位 | 规模线索 | 为什么入选 |
|------|-----------|---------|-----------|

## 逐家拆解
### 同行 A：<名字>
- 获客：<渠道 1（证据）>、<渠道 2（证据）>
- 转化：<步1 → 步2 → … → 付款>；客单价 / 报价方式
- 交付：<核心交付物 / 最重一环 / 大概人力>
- 能抄：……（第一步：……）
- 抄不动：……（缺什么：……）
- 别抄：……（为什么冲突：……）
### 同行 B / C / D / E：同构

## 我的三步行动
1. 本周：……
2. 下周：……
3. 一个月内：……
```

林姐档案里「同行 A」一页填完是这样：

```
### 同行 A：某抖音乐高编程矩阵号
- 获客：9 个抖音号日更「作品前后对比」视频（账号名可查）；评论区私信话术「回复测评领免费体验课」（截图已存）
- 转化：视频 → 私信 → 免费体验课 → 1 对 1 测评 → 999 正课；不报价时先送测评报告
- 交付：录播 + 每周直播答疑；最重一环是测评，约 2 名全职老师扛 600 学员
- 能抄：作品对比视频。第一步：本周用自家 3 个学员拍「课前 vs 课后」，发主号
- 抄不动：9 号矩阵。缺口：缺 3 个能日更的运营人力
- 别抄：无
- 校准（一周后）：对比视频带来 47 个私信，标「有效」；矩阵号暂缓
```

## 红线

- 每个获客动作都要有可核对的证据（账号名、链接、截图描述）；拿不出证据的写「待核实」，不许当事实引用
- 「能抄」清单每条必须写「第一步怎么开始」；只写「学它做短视频」不合格
- 同行必须 3~5 家，至少 1 家明显大于你、1 家和你体量相近；不够就回去补筛
- 「抄不动」的原因必须是具体缺口（缺 3 个运营人力 / 缺线下场地），不能写「我们还不够强」
- 全文不出现口号式大词和商业黑话——写完做一次「删词测试」：任何删掉后句意不变的词一律删掉

## 常见坑

- 只看头部：头部玩法常是大预算玩法，照抄容易死。名单里要有体量相近的一家。
- 把表面动作当策略：看到对方天天直播就学直播，没看到直播只是承接私域的收口。拆到路径层面再下结论。
- 抄话术不抄语境：同行话术在它积累的信任上有效，直接搬给冷启动账号，效果差很远。
- 档案写完就归档：没有带时间点的三步行动，档案只是收藏夹里的资料。
