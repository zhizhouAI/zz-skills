# zz-gzh-html · 公众号排版 HTML

## 一句话

Markdown 变公众号可直接粘贴的排版 HTML。

## 用与不用

适合用的场景：

- 一篇 Markdown 文稿要发公众号，想粘进后台就有基本排版
- 历史推文排版乱，想按一套固定样式重排
- 多个作者往同一个号投稿，想统一视觉口径
- 转载来的 Markdown 稿要进自己的号，重新套一套样式

不该用的场景：

- 要发知乎、头条等其他平台——各家样式规则不同，别硬套
- 想一次排版多平台通吃——各平台分开做，别偷懒
- 想要点击展开、SVG 动画这类交互——后台保存时会剥掉大部分脚本
- 文稿还没写完、结构未定——先定稿再排版，不然改一字排一遍

## 开工前要什么

必需信息：

- Markdown 文稿（贴文本或给文件路径）
- 品牌色，有一个强调色就够

可选信息：

- 读者构成（老年读者多的号可整体加大 1 号字）
- 图片链接（要能公网访问的图床地址；本地图片说明后续自己传素材库）
- 一条往期推文链接（想对齐历史风格时参考）

用户没给时的默认假设：

- 没给品牌色，用默认强调色 #c7254e，交付时注明可换
- 图片只有文件名，输出留占位标签，提醒先传素材库再替换链接
- 没说字号偏好，正文 16px、行高 1.75
- 没说对齐方式，正文左对齐，两端对齐不开（手机上更透气）

贯穿示例：母婴公众号「奶油妈妈」写了篇 1800 字《宝宝辅食添加时间表》，里面有 4 个小标题、23 个段落、1 段医生观点引用、3 条分割线、2 张图，还有 5 句想突出的重点句。号主说：「重点句要一眼看到，我妈群里转的就是那句满 6 个月。」又补了句：「颜色别太花，我妈那辈人看着舒服。」排完在 375px 宽度下无横向滚动，照步骤粘贴一次成功。

## 怎么做

1. **清点 Markdown 结构**

   做什么：逐块数并记下数量：
   - 标题几级几个；段落几段
   - 列表几组、每组几项
   - 引用几段、分割线几条、图片几张
   - 要强调的重点句哪几句（作者点名的优先）
   汇成一张结构清单。
   判断标准：后面 HTML 的块数和这张清单对得上，一块不少。
   中间产物：结构清单。示例：4 标题、23 段、5 组列表、1 引用、3 分割线、2 图、5 重点句。

2. **定一套样式基线**

   做什么：把数值定死，之后所有样式只从这套基线取，不临时发明。默认基线：
   - 正文：16px、行高 1.75、段距 14px、色 #333
   - 小标题：18px 加粗，上边距 28px、下边距 14px
   - 引用块：左侧 4px 竖线、浅灰底、内边距 10 到 14px
   - 分割线：1px 浅灰细线，上下留白 24px
   - 图片：max-width 百分百、居中、下边距 14px
   判断标准：全篇颜色不超过 2 种（正文深灰＋强调色），字号不超过 3 档。
   基线表贴进交付文件的头部注释，日后换风格照着改一处就行。
   中间产物：样式基线表。

3. **逐块转成内联样式 HTML**

   做什么：每个标签的样式全写进 style 属性。不写 style 块、不用 class——公众号后台保存时会剥掉它们，样式就全丢了。
   顺带规则：段落之间不留空标签，间距全靠 margin 撑。
   判断标准：文件里搜不到 style 标签和 class 属性这两个字符串。
   中间产物：初步 HTML 文件。

4. **定制特殊块**

   做什么：按基线逐个做特殊块：
   - 引用块：左侧 4px 竖线加浅灰底
   - 分割线：1px 浅灰细线
   - 重点句：加粗加强调色
   - 列表：项目间距 8px，嵌套不超过两层
   - 图片：max-width 百分百并居中
   判断标准：特殊块和普通段落一眼能区分，但风格仍在同一体系里。
   中间产物：带特殊块的 HTML。示例：医生观点做了引用块；「满 6 个月再添加辅食」红字加粗。

5. **375px 手机宽度预览**

   做什么：把浏览器窗口缩到 375px 宽，逐屏检查：有没有横向滚动、每行是不是 22 到 26 字、间距会不会挤成一团、标题有没有孤零零挂在屏底。
   检查重点：引用块在窄屏会不会换行错位；分割线上下留白够不够。
   判断标准：无横向滚动、无贴边文字、无孤行标题。
   中间产物：问题修正记录。示例：修掉两处多余空行、一张超宽图。

6. **输出单文件＋粘贴步骤**

   做什么：交付一个 HTML 文件，头部注释写清粘贴步骤：浏览器打开、全选、复制、到公众号后台编辑器粘贴、手机预览确认一遍。
   文件命名：用拼音或英文短名，别用中文带空格的路径，浏览器打开不踩编码坑。
   判断标准：没碰过这个文件的人照步骤一分钟能粘完。
   中间产物：最终 HTML＋步骤说明。示例：奶油妈妈照注释粘完，后台里样式完整。

## 交付长什么样

```html
<!-- zz-gzh-html 输出：fushi.html -->
<!-- 样式基线：正文16px/行高1.75/段距14px/正文#333/强调#c7254e -->
<!-- 粘贴步骤：1) Chrome 打开本文件 2) Ctrl/Cmd+A 全选 3) Ctrl/Cmd+C 复制
     4) 公众号后台编辑器内 Ctrl/Cmd+V 粘贴 5) 右侧手机预览确认样式齐全、不横滚 -->
<section style="max-width:677px;margin:0 auto;font-size:16px;line-height:1.75;color:#333;">
  <h2 style="font-size:18px;font-weight:700;margin:28px 0 14px;">满 6 个月，再开始加辅食</h2>
  <p style="margin:0 0 14px;">很多家长问到底几个月加。记住这句就够：<strong style="color:#c7254e;">满 6 个月再添加辅食</strong>。</p>
  <p style="margin:0 0 14px;">加早了肠胃受不了，加晚了营养跟不上。判断信号有两个：能扶坐、挺舌反射消失。</p>
  <blockquote style="margin:0 0 14px;padding:10px 14px;border-left:4px solid #ddd;background:#f7f7f7;">儿科医生提醒：第一口辅食从强化铁米粉开始。</blockquote>
  <ul style="margin:0 0 14px;padding-left:20px;">
    <li style="margin:0 0 8px;">6 至 7 个月：原味米粉、菜泥</li>
    <li style="margin:0 0 8px;">8 至 9 个月：碎软面、蛋黄</li>
  </ul>
  <hr style="border:none;border-top:1px solid #e5e5e5;margin:24px 0;" />
  <img src="图床或素材库链接" style="max-width:100%;display:block;margin:0 auto 14px;" />
  <p style="margin:0 0 14px;">图 1：各月龄辅食性状对照（先在素材库传图，再替换这里的链接）</p>
</section>
```

交付时文件头部注释里的粘贴步骤按这个顺序写，照抄不省略：

1. 用 Chrome 打开输出的 HTML 文件
2. 全选（Ctrl/Cmd+A）并复制
3. 打开公众号后台图文编辑器，正文区直接粘贴
4. 右侧手机预览：看字号、引用块、分割线、图片是否都在
5. 有图片占位的，先在素材库传图，替换链接后再预览一次

最后那步手机预览不许省，很多人就栽在没预览。

## 红线

- 文件里搜不到 style 标签和 class 属性，全部样式都在各标签的 style 属性里（验证：全局搜索两次，都零命中才算过）
- 正文统一 15 到 17px、行高 1.7 到 1.9、段距 10 到 20px，逐段数值一致，不许一段一个样
- 所有图片标签带 max-width 百分百，375px 宽度下无横向滚动
- HTML 块数与结构清单一一对应：Markdown 里每个标题、段落、列表项、引用都有落点
- 强调色全篇最多 1 种，正文用深灰不用纯黑

## 常见坑

- 直接复制渲染后的整页网页，把导航栏和背景色一起粘进后台
- 用了 CSS 变量或外部字体，保存时被剥掉，样式全丢
- 图片写了本地相对路径，粘过去全是裂图，要先传素材库换链接
- 用连打的 br 标签撑段距，后台二次编辑时全乱，段距要用 margin
