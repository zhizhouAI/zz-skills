# zz-hit-autopsy · 爆款复盘

## 一句话
拿结果倒推原因，拆出能复用的规律。

## 用与不用

适合用：

- 一条内容数据明显好于日常，想知道哪些东西值得留下来反复用
- 一条内容明显扑了，想知道死在哪一环
- 老板或客户追问「那条为什么火」，需要一个说得清、拿得出手的解释
- 想把偶然一次的成功变成可重复的做法
- 同类内容做过好几条、忽好忽坏，想知道好坏差在哪里

不该用：

- 内容刚发几个小时，数据还在爬坡——等 48 小时再复盘
- 内容几乎没有数据（播放三位数、评论个位数）——样本太小，先攒量
- 只想听表扬——复盘会同时指出好运和风险，不想听就别开
- 量主要是投流买来的——先扣掉投流部分再看自然表现，否则归因全错

## 开工前要什么

必需：

- 内容本身：链接、文案或视频文件
- 核心数据：播放/阅读、点赞、评论、转发、涨粉，有什么给什么
- 发布时间，和你平时的平均水平

可选：

- 评论区原文，尤其高赞评论
- 流量来源构成：推荐、搜索、关注各占多少
- 发布时你做了什么：投流、互推、蹭了什么热点
- 完播率或跳出曲线（能拿到就一定要给）
- 同期有没有同类热点（判断是否被热点带量）

用户没给时的默认假设：

- 拿不到来源构成，按「全靠自然推荐」处理，并在结论里写明这个限制
- 平时水平没给，就追问「你最近 10 条的中位数大概是多少」
- 所有归因先标「假设」，要靠下一条内容验证
- 完播曲线拿不到，就只按互动指标归因，不猜「第几秒掉人」
- 拿不准的宁可写两个候选原因加验证办法，不写单一结论

## 怎么做

全文沿用同一个例子：阿蓉的家庭情感号（抖音 2.3 万粉）。那条「我把妈妈 20 年前的老照片修复了，她哭了」播放 320 万、点赞 28 万、转发 9.7 万、评论 2.1 万、涨粉 4.6 万。

问阿蓉平时水平，她翻了后台：「最近 10 条，高的 1.5 万，低的 8000，就按 1 万当中位数吧。」——基线用这个 1 万。发布时间她也补了一句：「5 月 4 日晚上 8 点发的，快到母亲节了。」——先记进「不可复制」候选。

1. **定基线，找异常指标。**
   - 做什么：算出这条相对平时水平的倍数，找出最异常的那一项。
   - 判断标准：基线用自己的中位数，不用别人的爆款；异常要写成对比，比如「转发 8 倍、点赞 3 倍，转发最异常」。
   - 中间产物：异常指标卡。
   - 示例：转发约为平时的 8 倍，点赞约 3 倍，播放约 30 倍——转发行为最异常，后面重点拆「为什么有人转」。

2. **读评论区，给评论分类。**
   - 做什么：把高赞评论分成四类：共鸣型（「我也是」）、行动型（「我今晚就去做」）、争论型（「不对吧」）、转发理由型（「@姐姐 你看」）。
   - 判断标准：能说出哪类最多，并摘至少 3 条原话；评论区读不出信号就承认「评论区信号弱」，改从内容文本推，并标明。
   - 中间产物：评论分类表（类目 / 占比 / 原话）。
   - 示例：最多是共鸣型——高赞第一「想起了我爸，他手机相册里全是我的截图，没有一张他自己」；其次是行动型「今晚就问问爸妈还有没有老照片」。

3. **定位共鸣点。**
   - 做什么：回到内容里，指出触发共鸣的具体位置：哪一秒、哪句话、哪个画面，并说出背后的人群情绪。
   - 判断标准：共鸣点必须能引用原句或描述原画面；指不到位置的只能标「疑似」，并写验证办法。
   - 中间产物：共鸣点定位卡（位置 / 原句 / 人群情绪）。
   - 示例：位置在 1 分 12 秒，妈妈看到修复照片说「这是我年轻时候啊」。背后情绪是子女的亏欠感——平时欠父母一次郑重的注视。

4. **拆传播理由。**
   - 做什么：回答「别人为什么愿意转」：替他说话、有用、有面、站队，选主因，并写出「转给谁看」。
   - 判断标准：最异常指标是转发时必须重点做；写出一句「这条要转给谁」的白话。
   - 中间产物：传播理由卡。
   - 示例：转发语境是发给兄弟姐妹或家族群。一句话版本：「这条要转给你姐，让她也回家翻翻相册。」属于「替转发者表达情感债」。

5. **分栏：运气和规律。**
   - 做什么：把成功因素分两栏。可复制：选题、结构、钩子、情绪点；不可复制：时间点、平台活动、被大号顺手转发。
   - 判断标准：两栏都不许空；「可复制」每条要写「下次怎么触发」，写不出就挪到「疑似运气」。
   - 中间产物：运气/规律两栏表。
   - 示例：可复制——修复前后的视觉反差开场、面向 30~60 岁的情感债主题、结尾不喊口号只留妈妈一句引语；不可复制——发布恰逢母亲节前一周、被两个百万粉情感号转发。

6. **写下一条怎么用。**
   - 做什么：把规律变成下一条的 2~3 个具体动作，并写清「如果没火，怎么判断是规律错了还是运气差」。
   - 判断标准：每个动作都能在下一条里落地；验证办法要能区分两种失败原因。
   - 中间产物：复用行动卡。
   - 示例：下一条做「我陪爸爸重走他年轻时上班的路」，沿用三件事：反差素材开场、情感债主题、家人引语收尾。若没火，先看发布时间是否撞上冷时段——区分规律错还是时间差。

## 交付长什么样

```
# 爆款复盘：<内容标题>
日期 / 平台 / 发布至今时长

## 基线与异常
- 平时水平：播放~ / 赞~ / 转~ / 评~
- 本条：播放 / 赞 / 转 / 评 / 涨粉
- 最异常指标：……（倍数对比）
- 完播 / 流量来源（拿得到才填）：……

## 评论区信号
- 分类占比：共鸣 x% / 行动 x% / 争论 x% / 转发理由 x%
- 原话摘录：1.…… 2.…… 3.……

## 共鸣点
- 位置：第 x 秒 / 第 x 段；原句或画面：……
- 背后的人群情绪：……

## 传播理由
- 转发语境：转给谁、替他说什么
- 一句话版本：……

## 运气与规律
| 因素 | 归类 | 下次怎么触发 / 规避 |
|------|------|--------------------|

## 下一条怎么用
1. ……
2. ……
- 验证办法：没火时怎么区分规律错 / 运气差
```

阿蓉的「下一条怎么用」填完是这样：

```
1. 开场 3 秒用前后反差素材（爸爸 25 岁的工牌 vs 现在），替换原片的照片修复开场。
2. 主题定为「陪爸爸重走上班的路」，继续打 30~60 岁的情感债。
3. 结尾只留爸爸一句原话「这条路走了 30 年，没想到有人陪」，不喊关注。
- 验证办法：若播放回到日常水平但转发率正常，是选题人群变窄；若开头 5 秒跳出率明显升高，是反差开场失效。
- 顺手动作：评论区置顶「你爸妈还有哪些老照片？」，把共鸣转成评论。
```

## 红线

- 每个共鸣点必须能指到内容里的具体位置并引用原句或描述画面；指不到的只能标「疑似」，并附验证办法
- 归因先看数据再讲故事：最异常的指标没找出来、没解释，复盘不算完成；转发异常却不拆传播理由算失职
- 「可复制」栏每条都要写「下次怎么触发」，写不出的必须挪进「疑似运气」
- 引用评论区必须摘原话，不许概括成「大家都很感动」这种没法核对的说法
- 全文不出现口号式大词和商业黑话——写完做一次「删词测试」：任何删掉后句意不变的词一律删掉

## 常见坑

- 把结果当原因：「它火了所以选题好」。先找异常指标，再回到内容里指位置。
- 复盘夸自己：只列做对的，不列运气。运气栏空着的复盘不可信。
- 立刻复刻到变形：下一条把引语、反差、句式全塞进去，反而假。每次复用两三件事就够。
- 翻车复盘只写「下次努力」：翻车更要指到死的位置——第几秒掉的人、哪句话引来的争论。
