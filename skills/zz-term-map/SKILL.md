# zz-term-map · 概念地图

## 一句话
同一个词不同场合意思不同，先选定这次用哪个。

## 用与不用

适合用的场景：
- 开会或讨论前，发现大家都在说"私域""增长"，但各说各的。
- 用户要写文章或做汇报，核心概念没定义，写着写着就飘。
- 一个词在行业里吵得很凶，用户想知道到底谁对——其实是场合不同。
- 用户被多个"专家"的说法绕晕了，想理清哪个说法对自己有用。
- 合同或报价单里出现了核心概念却没写定义，签字之前要先对齐。

不该用的场景：
- 词义有公认精确定义且无争议，比如"毛利率""复权价"。
- 纯学术考据，用户要的是这个词的词源和演变史，不是实用定义。
- 问题根本不在概念上。讨论卡住是因为数据没给、人没到齐，别拿定义凑热闹。
- 词是新造的内部黑话，只在一个小团队里流通。直接问造词的人最快，画地图是绕路。

## 开工前要什么

必需信息：
- 要定义的词是什么，用户在什么场合遇到它。
- 本次讨论要做的决定是什么。选定义是为了做决定，没有决定就没有"该用哪个"。

可选信息：
- 用户听过哪几种说法，分别是听谁说的。
- 行业、公司规模、用户所在的角色，这些决定哪些场合的定义跟用户有关。
- 手头的合同或报价单原文。概念没写定义的合同，是冲突高发地。

用户没给时的默认假设：
- 默认用户是实操者，不是研究者。定义要落到"接下来做什么"上，不落到学术流派上。
- 默认本次讨论以用户的行业为准，跨行业的定义只做对照，不做主体。
- 场合罗列以 3 到 5 个为限，多了砍掉和本次决定无关的。
- 默认对齐卡只服务本次讨论。下次换了决定，可能要重新选定义，别复用旧卡。

## 怎么做

贯穿示例：开烘焙店的小蒋要跟代运营公司谈"私域运营"合同，谈之前她问："私域到底是个啥？他们报价单上写'私域月费 6000'，我心里没底。"
她听过的说法已经打了架：做电商的朋友说私域就是微信群发券，短视频博主说私域是"企业的第二增长曲线"。两个都听着有理，就是凑不到一块。她的顾虑很实际：一个月 6000 元，买的到底是哪种"私域"。

### 第 1 步：收集这个词出现过的场合
做什么：列出这个词平时由谁在说、在哪里说、说的时候一般在做什么决定。每个场合记一行。
判断标准：至少三个场合，且至少有一个跟用户处境相近。小蒋这个例子里有四个：品牌方老板、代运营服务商、平台运营、单店店主。
找场合的线索：聊天记录、报价单、行业群聊、刷到的视频。谁在收钱、谁在担责，谁的场合就最值得查。
中间产物：场合清单，每行格式为"谁 / 在哪说 / 说完通常干什么"。

### 第 2 步：给每个场合写动作版定义
做什么：不写词典解释，写"说这个词的人，接下来会做什么动作"。定义跟着动作走。
词典可以查，但只当对照组：词典定义和动作版差得越远，说明这个词在实战里漂得越厉害。
判断标准：每个定义配至少一个具体动作。小蒋排查下来的四个版本：
- 品牌方说私域：指企微好友加社群，接下来是建群拉人、发内容、做复购。
- 代运营说私域：指"能反复免费触达的用户池"，接下来是出社群排期表、报月费。
- 平台运营说私域：指用户离开平台后能不能被找回，接下来是盯站外导流、判违规。
- 单店店主说私域：指老客微信群，接下来是逢年过节发优惠券、发上新。
中间产物：动作版定义表，一场合一行。

### 第 3 步：把冲突点摆上台面
做什么：找出动作直接打架的地方。同一件事，甲场合叫常规操作，乙场合叫违规。
冲突也不一定是违规层面，可能只是目标不同：一个要复购，一个要流水，同一句话各说各的。
判断标准：冲突必须写到"谁的做法会让谁吃亏"的层面。小蒋这个例子里最实的一条：代运营说的"私域用户池"，如果靠从平台往微信导流攒起来，店铺在平台那边可能被判违规，罚款的是小蒋不是代运营。
轻的冲突也要记：店主版私域（发券群）和品牌方版私域（内容社群）动作差一截，报价自然差一截，不挑明就说不清月费含什么。
中间产物：冲突清单，每条写明"甲场合的做法 + 乙场合的判断 + 吃亏的是谁"。

### 第 4 步：找共同核
做什么：把所有场合都包含的成分挑出来。比如"私域"的共同核是：用户名单在自己手里、能反复触达、单次触达不另付费。
共同核用来认词，不用来定标准。标准由第 5 步的选定定义给。
判断标准：共同核必须经得起反例检验——找一个边缘事物，用共同核判断它算不算，说得通才算成。
示例：付费会员短信推送——名单在平台手里，触达按条付费，两条都不满足，不算私域，检验通过。
中间产物：共同核描述，一两句话。

### 第 5 步：列候选定义，选定一个
做什么：把适合本次决定的定义写成一句话，明确选定。判断标准有两条：跟本次要做的决定直接挂钩；给任何一件具体的事，这句话能判定它"算"还是"不算"。
小蒋的选定："本次谈合同，私域=以我的店铺名义建立、用户主动加进来、我可以随时免费触达的用户群（企微+社群）。平台站外导流攒来的名单不算。"
判断标准：选定的定义念给用户听，用户能当场举一个例子问"那这个算吗"，你能不犹豫地回答。
选不动的时候，把候选定义分别带进本次要做的决定里过一遍：哪个定义能让决定立刻变清楚，就选哪个。定义是为决定服务的。
中间产物：选定定义一句话 + 两个判定示例（一个算、一个不算）。

### 第 6 步：写进讨论约定
做什么：把选定定义和排除范围写成一页，讨论或合同谈判时摆在明处。边界情况事先定裁决规则，比如"短信触达算不算？按'名单是否在自己手里'裁"。
判断标准：约定里有明确的排除项，且边界规则覆盖至少一个最容易吵的情况。
写完自测一遍：假装对方抬杠"那企业微信朋友圈算不算"，约定里能找到裁决依据才算过。
中间产物：概念对齐卡（模板见下一节）。

### 第 7 步：讨论中守约
做什么：讨论或谈判过程中，有人说的话越出了选定定义，就当场提醒一句"按对齐卡，这个不算私域"。提醒要轻："等等，对齐卡上说了这个不算——你是想说它算，还是想换个词？"别拿卡压人。
判断标准：同一处越界出现第二次，回头查第 2 步，可能漏了一个场合。
中间产物：对齐卡更新记录（有则记，无则不写）。

## 交付长什么样

```
# 概念对齐卡：私域（用于小蒋 × 代运营合同谈判，2026-11）

## 这个词在四个场合下的意思
1. 品牌方老板：企微好友+社群，动作是建群、发内容、做复购。
2. 代运营服务商：能反复免费触达的用户池，动作是出社群排期、
   报月费。
3. 平台运营：用户离开平台后能否找回，动作是盯站外导流，判违规。
4. 单店店主：老客微信群，动作是发券、发上新。

## 冲突点（要当心）
代运营的"用户池"如果靠平台站外导流攒起来，平台可能判店铺
违规，罚款落在店主头上，代运营不担责。

## 本次讨论采用的定义
私域 = 以小蒋店铺名义建立、用户主动加进来、可随时免费触达的
用户群（企微+社群）。
判定示例：顾客扫码进企微 → 算；买粉丝通广告推给老客 → 不算。
发企业微信朋友圈广告 → 不算：触达按投放付费。
给 200 个老客群发短信 → 不算：短信按条付费，只算普通触达。

## 排除范围
- 花钱买的广告触达，不算。
- 从平台评论区导流攒来的名单，不算（且有违规风险）。
- 平台付费会员推送，不算：名单不在小蒋手里，触达按条付费。

## 边界裁决规则
某做法算不算私域，看两条：名单在不在自己手里；触达一次
要不要再付费。两条都满足才算。

## 谈合同时要问对方的三个问题
1. 你们说的"私域用户数"，名单存在谁手里？
2. 涨粉手段里有没有站外导流？违规责任谁担？
3. 每月 6000 元里，建群、内容、活动各占多少？

## 一句话结论
对方嘴里的"私域"和你要的"私域"是不是同一个东西，
把对齐卡拍在桌上那一刻就清楚了。
```

## 红线

- 每个场合的定义必须配具体动作。只写抽象解释（如"私域是一种用户资产"）不配动作的，不收。
- 罗列的场合 3 到 5 个，且至少有两个场合的典型动作互相冲突。全是和气场合说明没找对。
- 选定的定义必须能判定具体事项的"算/不算"。写完自己举两个例子测，测不出结果就重写。
- 必须写明排除范围。只写包含不写排除，不算完成。
- 全文不许出现"这个词的唯一定义是"。选的是"本次用哪个"，不是"哪个对"。

## 常见坑

- 只查词典不问人。词典定义四平八稳，真正的冲突只藏在具体人群的做法里。
- 定义选得太宽。"能反复触达用户的都算私域"听着全面，等于没选，讨论照旧打架。
- 忘了写边界规则。讨论半小时后卡在"发短信算不算"，没有事先规则就得重吵一遍。
- 把对齐卡写成长文。对齐卡是谈判桌上摆的一页纸，超过一页没人看。
