# zz-human-tone · 真人口吻改写

## 一句话

改成真人随手打出来的话，每处改动说清为什么。

## 用与不用

适合用的场景：

- 客服回复模板腔重，顾客说"你是机器人吧"
- 老板让你把 AI 生成的回复过一遍，要像自己人写的
- 微信里给顾客、邻居、合作方的消息读着太客气，不像你会说的话
- 差评回复、售后安抚，想让对方感到是个人在处理
- 家长群、业主群里回消息，想不卑不亢，不像复制粘贴的

不该用的场景：

- 公告、通知、合同条款——这些本来就该书面
- 品牌官微的统一口径——官号有自己的语气规范，别乱动
- 要补没发生过的承诺，比如"一定赔"——那不是语气问题，是事实问题
- 对方在等一个正式答复，比如投诉已经升级到平台了

## 开工前要什么

必需信息：

- 原消息全文
- 谁发给谁：你的身份、对方身份、什么关系（头回接触还是老客）
- 什么渠道：微信私聊、群、评价回复区

可选信息：

- 你平时的说话习惯，有没有口头禅
- 这件事的真实处理进度，方便把"等待"换成"承诺时间"
- 有没有不能说、不能承诺的边界
- 对方上一条消息的原文，方便接得住对方的话头
- 这条回复的出处：随手写的，还是从话术库里挑的模板
- 词表：优先加载本仓库 `shared/wordlists/` 下的最新词表（AI 腔黑名单 / 包装词黑名单 / 平台风险 starter 词表），本技能内置示例仅作兜底

用户没给时的默认假设：

- 没说关系，按"和陌生顾客的第一次接触"处理，保留"您"
- 没说处理进度，就不新增任何时间承诺，只删不改事实
- 没说语气偏好，按"客气但不客套"改
- 没说是私聊还是群里，按私聊改；群里的场合要再收着一点
- 没给对方身份，一律按顾客处理，同事腔不适用
- 改完按"对方在手机上扫一眼"的标准读，不按文章标准读

## 怎么做

全程用一个例子跟走：健身房客服用 AI 生成了一条回复。会员发消息说跑步机扶手松动，客服直接复制粘贴了下面这段，会员回了一句"你是机器人吧"。

原消息：

> 亲爱的会员您好，非常抱歉给您带来不便，您反馈的问题我们已经第一时间同步至相关部门进行核实，请您耐心等待，如有进一步消息我们会第一时间与您联系，感谢您的理解与支持！

1. **圈场景**

   - 做什么：写清谁发给谁、什么渠道、什么关系，定语气档位。
   - 判断标准：一句话能说出"这是谁对谁、在什么场合说话"。
   - 中间产物：场景卡。本例是客服对老会员，微信私聊，语气要熟络但靠谱。

2. **圈模板句**

   - 做什么：划出所有"放在任何公司任何群都成立"的句子——称呼套话、致歉套话、感谢套话、"请耐心等待"。
   - 判断标准：一句一句问"这话换个店还能用吗"，能，就是模板。
   - 中间产物：模板句清单。本例 5 处全标了。

3. **换具体**

   - 做什么：把抽象名词换成具体的人和事——"相关部门"换成具体谁，"问题"换成什么问题。
   - 判断标准：改完的句子里能找到人名、物品名或时间点，至少一样。
   - 中间产物：具体化稿。本例"同步至相关部门"换成"报给维保的张师傅"。

4. **念出声修短句**

   - 做什么：把稿子念一遍，一口气念不完的拆短；按关系定"您"还是"你"。
   - 判断标准：每句一口气能念完；称呼档位和场景卡一致。
   - 中间产物：朗读稿。本例最长一句拆成了两句。

5. **出全文**

   - 做什么：按原顺序整理成可直接发送的全文，事项不增不减。
   - 判断标准：原文里的每个事实都还在，没多出新的承诺。
   - 中间产物：修订全文。

6. **配原因表**

   - 做什么：每处改动一行，写"原来什么、改成什么、为什么"。
   - 判断标准：每行原因是一句大白话，能对上具体的字词。
   - 中间产物：改动说明表。

7. **通杀句终检**

   - 做什么：在改后全文里再找一遍"任何公司都能用"的句子，找到就再删。
   - 判断标准：全文没有一句能原样搬到别家去用。
   - 中间产物：终稿草稿。

8. **预演对方回复**

   - 做什么：假装自己是收信人，读一遍终稿，写出对方最可能回的那句。
   - 判断标准：对方能接得上话；如果只能回"好的谢谢"，说明还是模板感，回第 3 步。
   - 中间产物：预演回复，跟终稿一起交付。本例预演会员会回"好的，下午等你们消息"，能接上，过关。

## 交付长什么样

```
场景：健身房客服 → 老会员，微信私聊，售后反馈
改后全文：
不好意思，这个是我们没跟上。您说的跑步机扶手松动，我已经报给维保的
张师傅了，今天下午 5 点前给您准信。有事直接微信喊我。

改动说明（每处一行）：
1. "亲爱的会员您好" → 删。微信私聊没人这么开头，一开口就远了
2. "非常抱歉给您带来不便" → "不好意思，这个是我们没跟上"。
   短一半；"带来不便"说不出具体是什么，"没跟上"认了具体的事
3. "第一时间同步至相关部门" → "报给维保的张师傅"。
   有具体的人，顾客才知道这事真有人管
4. "请您耐心等待，如有进一步消息我们会第一时间与您联系" →
   "今天下午 5 点前给您准信"。把等待换成承诺时间，顾客心里有底
5. "感谢您的理解与支持" → 删，换成"有事直接微信喊我"。
   模板感谢删掉，换成一句能继续对话的收尾

检查结果：全文没有能搬到别家用的通杀句；未新增任何原文没有的承诺。
语气档位：对老会员，客气但熟络，保留"您"。

如果想再熟一档（对方是每周都来的熟客）：
这事是我们没跟上，张师傅下午去看，5 点前给你信儿。
档位说明：去掉"您"，改成口语的"给你信儿"，承诺时间不变。
```

## 红线

- 交付的是完整全文，能直接复制发送，不是片段
- 每处改动在说明表里有对应一行原因
- 不新增原文没有的承诺、金额、时间点；想加，先问用户要授权和事实
- 原文的关键事实（单号、金额、时间、物品）一个都不许改错
- 语气档位写明：对顾客、对同事、对领导不是一套写法，交付里注明用的哪档

## 常见坑

- 客气删过头，变成冷淡。删的是套话，不是礼貌
- 只改称呼，正文还是"已同步相关部门"。模板句在正文里，不在称呼里
- 顺手加新方案，比如"这几天可以用 3 号机"——没跟业务确认就加，比模板腔更伤人
- 改完不像这个人平时说话。拿不准就保留用户的口头习惯，别替他换人设
