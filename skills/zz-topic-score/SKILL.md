# zz-topic-score · 选题打分

## 一句话
动笔前五分钟，判断选题做不做。

## 用与不用

适合用：

- 手上有好几个选题，要先排优先级，决定这周做哪条
- 一个选题自己拿不准，怕写完没反响
- 打算投入大制作（约稿、出差拍摄、买素材）之前先过一道闸
- 团队例会上要快速定夺一批报上来的题目
- 甲方给了自由发挥空间，你要在几个方向里挑一个最稳的

不该用：

- 稿子已经写完或拍完——那是复盘，不是打分
- 选题是甲方指定、必须交的——直接进方案，打分白费心情
- 纯自留日记、不打算发布的内容，没有评分意义

## 开工前要什么

必需：

- 选题一句话
- 你账号的定位和粉丝量级
- 打算发的平台

可选：

- 你或同行做过的同类选题数据
- 你想抢的时间点（热点、节日、平台活动）
- 商业意图：接了单、要带货、纯涨粉
- 截稿时间
- 个人档案：若本机存在 `profile/` 目录（由 `zz-profile` 生成），先读 `生意档案.md` 和 `口癖词典.md`，让产出对齐档案；没有则跳过，不影响流程
- 校准记录：若 `profile/校准记录.md` 存在，读取历史预测偏差（由 `zz-result-loop` 维护），用于修正本次流量区间

用户没给时的默认假设：

- 没给历史数据，就按同体量账号的常见水平做区间估计，并标「估算」
- 没说商业意图，商业项按 0 记，并在结论里说明这个口径
- 打分是决策参考，不承诺数据结果
- 参照数据凑不齐三条，按「置信度低」处理，结论语气降半档

## 怎么做

全文沿用同一个例子：小雨的选题「月薪 3 万，我却不敢辞职」。她做职场号，小红书 8000 粉，公众号 3000 粉，打算发小红书。

1. **过资格闸：连问三个问题。**
   - 做什么：①我能拿到独特点吗（亲历、一手信息、独特视角）？②选题人群和我账号匹配吗？③这周做得完吗？
   - 判断标准：三问里有两问是「否」，直接进放弃候选，后面不用评了。
   - 中间产物：资格闸记录（三问三答）。
   - 示例：小雨 3 年前经历过 8 个月「不敢辞」——有亲历；她的粉丝 7 成是 25~35 岁上班族——匹配；素材都在手上——做得完。三问全过。

2. **写受众两行。**
   - 做什么：一行写「谁会点进来」，一行写「谁绝对不会点」，都要具体到人群。
   - 判断标准：会点进来的人要在你现有粉丝盘里占两成以上；两行写不出具体人群，说明选题偏了。
   - 中间产物：受众两行卡。
   - 示例：会点：25~35 岁、在大厂或准大厂、有存款焦虑的人；不会点：体制内稳定党、已经自由职业的人。

3. **写开头三选。**
   - 做什么：给选题写 3 个候选开头，必须是成品句，不是「从故事切入」这种方向描述。
   - 判断标准：至少 1 个能让目标人群产生「说的是我」的感觉；三个都写不出，说明钩子不够硬，选题降档。
   - 中间产物：开头三选卡。
   - 示例：①「银行卡余额 47 万，够躺 3 年半——我还是每天不敢辞职。」②「上周同事出事的当晚，我打开了招聘软件，又关掉了。」③「月薪 3 万不敢辞职的人，缺的不是钱，是『离开的剧本』。」小雨选①，数字最具体。

4. **找同类参照。**
   - 做什么：找你自己或同体量账号做过的同类选题数据，至少 3 条参照。
   - 判断标准：参照必须同平台、同量级；拿头部大号的爆款当参照无效，要标「无效参照」。
   - 中间产物：参照数据表。
   - 示例：小雨自己 3 个月前一条「存款焦虑」笔记 4.2 万阅读（她的账号最高纪录）；同类话题在这个粉量段常见区间是 5000~5 万。

5. **估流量区间。**
   - 做什么：结合参照估一个流量区间，不许给单一数字。
   - 判断标准：区间要注明参照来源；没有参照就标「置信度低」，并调低结论语气。
   - 中间产物：流量区间卡。
   - 示例：小雨估 8000~4 万阅读——参照是本人「存款焦虑」那条的 4.2 万，加同话题在同等粉量段的常见区间 5000~5 万。
   - 校准：若 `profile/校准记录.md` 存在且样本数 ≥5，先按记录里的「高估/低估」偏差比例修正本次区间，并在交付里注明「已按校准记录修正」；样本不足 5 次则照常给出区间，不引用校准。

6. **估商业价值。**
   - 做什么：判断这条能带来什么：带货、接单、人设、纯涨粉，各给量级或写「无」。
   - 判断标准：写清「涨粉之外还剩什么」；四项全空且流量区间不高，就降档。
   - 中间产物：商业价值卡。
   - 示例：能自然衔接她在测的「副业咨询」99 元服务，按 0.5% 转化估 2~4 单，另有人设积累。

7. **出三选一裁决。**
   - 做什么：综合资格闸、开头、流量、商业，给「直接做 / 改了再做 / 放弃」三选一。
   - 判断标准：「做」要能直接进方案；「改」要列出改动项；「放弃」要有一句理由并归档。不许出现第四种答案。
   - 中间产物：裁决卡。
   - 示例：资格全过、开头有成品、流量区间健康、商业有衔接——裁决「直接做」，接着进内容方案，主平台小红书，先做图文版。

## 交付长什么样

```
# 选题裁决：<选题一句话>
日期 / 平台 / 你的账号量级

## 资格闸
- 独特点：……（过/不过）
- 受众匹配：……（过/不过）
- 本周可完成：……（过/不过）

## 受众两行
- 会点进来的：……
- 绝对不点的：……

## 开头三选
1. ……
2. ……
3. …… → 选定：……

## 参照与估算
- 同类参照：1.…… 2.…… 3.……
- 流量区间：……~……（参照来源：……）
- 商业价值：带货 / 接单 / 人设 / 纯涨粉 → ……

## 裁决
- 结论：直接做 / 改了再做 / 放弃
- 若「改」：改动项是……
- 若「放弃」：理由一句话，归档待翻案
```

小雨的裁决卡填完，结论一行是：

```
- 结论：直接做。资格三问全过；开头①「余额 47 万还是不敢辞」已定稿；估 8000~4 万阅读（参照：本人「存款焦虑」4.2 万 + 同话题区间 5000~5 万）；商业上衔接 99 元副业咨询，估 2~4 单。
```

她「资格闸 + 受众两行」两节填完是这样：

```
## 资格闸
- 独特点：本人亲历 8 个月「不敢辞」，有具体细节（过）
- 受众匹配：粉丝 7 成是 25~35 岁上班族（过）
- 本周可完成：素材和案例都在手上（过）

## 受众两行
- 会点进来的：25~35 岁、有存款焦虑的大厂或准大厂员工（约占粉丝盘 70%）
- 绝对不点的：体制内稳定党、已经自由职业的人
```

## 红线

- 开头候选必须是写好的成品句；三个都写不出，只允许给「改了再做」或「放弃」
- 流量估算必须是区间并注明参照；没有同类参照时标「置信度低」，不许给单一精确数
- 裁决必须三选一，「可以做做看」「再想想」这类第四种答案不合格
- 「改了再做」必须列出具体改动项（换人群 / 换开头 / 缩小范围），写不出改动项就不许用这个结论
- 全文不出现口号式大词和商业黑话——写完做一次「删词测试」：任何删掉后句意不变的词一律删掉

## 常见坑

- 用「我觉得会火」代替判断：判断落在受众、开头、参照三样东西上，不落在情绪上。
- 把「有意义」当「有人看」：有价值但没流量的选题先归档，等账号做大再捡回来。
- 参照错位：拿百万粉大号的爆款当自己的预期。参照必须同平台、同量级。
- 打分后不归档：放弃的选题记一句理由，三个月后市场变了可能翻案。
