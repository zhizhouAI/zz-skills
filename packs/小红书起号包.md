# 小红书起号包

从 0 到 1 做一个小红书账号的完整闭环：建档 → 选题材 → 出方案 → 写钩子 → 改稿 → 查风险 → 发布后回填校准。7 个技能，一条链走完。

## 使用顺序

1. `zz-profile` — 第一次使用先建档：你的生意、目标人群、口癖词典（后面所有技能都会读它）
2. `zz-topic-score` — 想到一个选题先打分，值得做再动手
3. `zz-topic-plan` — 定下的选题出完整方案：形式、结构、基调
4. `zz-hook-three` — 按方案写标题/封面文字/开头，每平台 3 组备选
5. `zz-flat-fix` — 初稿写完，找出没打动人的段落删改补
6. `zz-risk-line` — 发布前逐句过风险，最小修改
7. `zz-result-loop` — 发布 48 小时后回填数据，校准你的预测，越用越准

## 第一次对话怎么开始

装好包后输入：

```text
/zz 我刚开始做小红书，做小红书起号
```

调度台会先带你建档，然后从选题开始一步步走。
