# 场景包（Packs）

一个场景包 = 精选技能组合 + 推荐使用顺序 + 目录约定。解决「36 个技能我不知道先用哪个」的问题。

## 可用场景包

| 包 | 技能数 | 适用 |
| --- | --- | --- |
| [小红书起号包](小红书起号包.md) | 7 | 从 0 到 1 做小红书账号 |
| [生意诊断包](生意诊断包.md) | 6 | 生意卡住，找病因开药方 |
| [副业起步包](副业起步包.md) | 7 | 想搞副业一直没行动 |

## 安装方式

```bash
./install.sh --pack 小红书起号包 <目标目录>    # 装包内技能 + 建目录约定
./install.sh --pack-list                      # 查看全部场景包
```

场景包按顺序用效果最好；单技能也可以随时单独调用。

## 自己配一个包

复制任意包文件改 `skills:` 列表即可；`setup_dirs` 会由安装脚本自动创建。
