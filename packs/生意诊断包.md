# 生意诊断包

生意卡住时的急救包：体检找病因 → 挖顾客动机 → 拆同行做法 → 拿条件答案 → 记录决定等回响。6 个技能。

## 使用顺序

1. `zz-profile` — 建生意档案：产品、客单、流量结构、当前最头疼的问题
2. `zz-biz-check` — 四问体检（谁付钱/为什么付/为什么流失/卡在哪），给出明天要做的第一件事
3. `zz-why-buy` — 找到最薄一环后，挖顾客到底为什么选你或放弃你
4. `zz-rival-file` — 拆 3~5 个同行怎么获客、转化、交付，找出能抄的第一步
5. `zz-best-answer` — 对具体问题拿带条件的答案：什么条件下该用什么打法
6. `zz-choice-log` — 把这次的决定记档，到期回填复盘

## 第一次对话怎么开始

```text
/zz 我做少儿编程课，40 个学员但续费很低，帮我查哪出了问题
```
