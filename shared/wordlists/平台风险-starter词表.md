# 平台风险 starter 词表

> 用途：`zz-risk-line` 发布前逐句检查的起步词表。
> ⚠️ 本表仅为起步参考，不构成合规意见。平台规则随时变化，**发布前以各平台官方规则原文为准**。
> 最后更新：2026-11-20（若发现规则变动，先改这里）

## 一、跨平台通杀类（各平台都限）

| 类别 | 典型词/行为 | 风险 |
| --- | --- | --- |
| 引流违禁 | 微信、VX、wx、加我、私信我（引导站外交易） | 限流/封号 |
| 联系方式变体 | ｖｘ、威信、+V、抠抠、Q群 | 限流 |
| 极端言行 | 自杀、自残细节描写 | 删除/封禁 |
| 迷信 | 算命、改运、开光、辟邪（售卖向） | 删除 |
| 资金盘 | 互助、拉人头、静态收益、动态收益 | 删除/上报 |

## 二、公众号强管类

- 医疗：治愈率、有效率、患者 XX 例全部好转（需资质）
- 金融：稳赚、保本、内部消息、荐股（需资质）
- 其他主体转载未授权内容 → 侵权投诉

## 三、小红书强管类

- 医美：瘦脸针、水光针（无资质发布）
- 素人广告未报备：关键词植入品牌名 + 购买引导
- 虚拟货币、彩票相关
- 「私信」「主页」引流电商外链

## 四、抖音/视频号强管类

- 口播出现：微信、扫二维码（画面+语音都查）
- 医疗科普非认证账号：疾病诊疗建议
- 财经非认证账号：个股推荐、收益承诺
- 素材版权：影视cut、背景音乐未授权

## 五、B站强管类

- 恰饭未标「含广告创作激励」
- 时政敏感话题区（无资质账号）
- 游戏私服、外挂相关

## 使用规则

1. 本表是「starter」：只覆盖高频高危，**不等于全部风险**；商单、持牌行业（医疗/金融/法律/教育）必须另做专业合规
2. 检查顺序：先跨平台通杀类，再按目标平台查专属类
3. 每处命中输出：风险等级（高危/中危/低危）+ 最小修改方案 + 依据类别
4. 词表更新流程：发现新规则 → 追加到对应平台小节 → 修改本文件头部「最后更新」日期
