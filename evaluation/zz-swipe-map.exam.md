# zz-swipe-map · 技能考题

适用版本：v1.1.0 ｜ 题数：3 ｜ 用法：把「输入」原文交给装好本技能的 Agent，对照「合格要点」逐条核对产出

---

## 考题 1 · 60 秒收纳口播发前体检（常规）

- 场景：你是家居博主，写完一条 60 秒收纳口播稿，自己念着总觉得别扭但说不出是哪句，发布前让 Agent 做最后一遍体检。
- 输入：这是条 60 秒的收纳口播稿，纯口播没配画面，帮我顺一遍，标出观众最可能划走的位置。
大家好，欢迎来到我的频道，今天给大家分享一下关于收纳的一些心得体会。首先我们要明白一个概念，收纳的本质是什么呢？收纳的本质其实是对物品进行科学化、系统化的分类管理。其次，我们需要选择合适的收纳工具，市面上各种各样的收纳产品可以说是琳琅满目，让人眼花缭乱，我们一定要结合自身的实际需求，理性消费，切勿盲目跟风。最后呢，收纳是一个长期的过程，需要我们持之以恒地坚持下去，养成良好的生活习惯，从而真正实现井井有条的美好生活。综上所述，收纳并没有大家想象的那么困难，只要掌握正确的方法，每个人都可以成为收纳达人。
- 合格要点：
  - 每句标了起止秒数，估算口径写明（每秒 4~5 字），全稿估时和 60 秒目标对照后给出结论
  - 拗口处引用原句并归到三类之一：超 25 字不换气的长句（如"市面上各种各样的收纳产品可以说是琳琅满目"）、书面词（"综上所述""持之以恒"）、绕口组合
  - 划走点全部标到秒，原因对着那句台词说（比如"0:06 还没告诉观众这条视频能给他什么"），归入没信息、拖节奏、听不懂、承诺落空四类之一；高危处必附可直接替换的新台词，长度变化不超过原句 ±30%
  - 改完复算总时长，变化超 ±10% 会标出来；同时圈出过关段并给理由（比如"收纳本质是分类管理"这句判断本身没错，只是念法问题）
- 常见失败：
  - 通篇评"节奏偏慢、书面语较多"，没有一处标到秒
  - 每处改法都越写越长，改完不复算时长

## 考题 2 · 开头夸了口却没兑现（边界）

- 场景：你是水果店老板，拍抖音带货口播，稿子开头喊"3 个诀窍"，正文只写了 2 个，你自己没发现，也没告诉 Agent 目标时长。
- 输入：帮我看看这条口播稿顺不顺，会不会被划走，发抖音用，大概 150 字：
今天教大家 3 个挑西瓜的诀窍，学会再也不怕买到生瓜。第一个诀窍，看纹路。纹路清晰而且间距宽的瓜，成熟度更高。第二个诀窍，拍一拍。声音清脆的是生瓜，声音沉闷的是熟瓜。最后，再教大家一招储存方法，西瓜买回来不要直接放冰箱，常温阴凉处放两个小时，口感会更好。关注我，下期教大家挑榴莲，可能会做。
- 合格要点：
  - 没给明确目标时长，按每秒 4~5 字估算并写明口径，报出估出的总时长
  - 做了承诺对照：开头说"3 个诀窍"，正文只有 2 个，在承诺兑现前的位置标为划走点，标到秒，原因归入"承诺落空"
  - 结尾"可能会做"识别为没承诺的落空点，给出可直接替换的台词（比如"评论区说你们还想挑啥，点赞过千下期就讲"）
  - 划走点全部标秒数、带原因、高危附改法；标出过关段并给理由（比如"纹路清晰间距宽"这条建议本身具体可用）
- 常见失败：
  - 只查拗口，没对照承诺，漏掉"说 3 个只讲 2 个"这个最大的划走点
  - 时长估算不写口径，直接说"这条大概 35 秒没问题"

## 考题 3 · 拿已播视频的分镜表来体检（刁钻）

- 场景：你是本地生活探店团队的剪辑，上一条视频完播率只有 11%，老板让你找 Agent"看看观众第几秒划走的"。你手里只有已播出视频的分镜表（镜号、画面、台词），没有逐字稿，还想让 Agent 顺便说说剪辑哪里切快点。
- 输入：我们上条探店视频完播率才 11%，帮我看看观众第几秒划走的，顺便告诉我们剪辑哪里可以切快点。分镜表在这：
镜 1（5 秒，街景空镜）：字幕"周末去哪吃？"
镜 2（8 秒，老板炒菜）：台词"这家藏在巷子里的小店，很多本地人都在吃"
镜 3（12 秒，菜品特写）：台词"招牌是牛杂锅，一份 38，分量特别足，而且他们家的汤底是用牛骨熬制的，非常浓郁醇厚"
镜 4（10 秒，客人吃）：台词"总之这店我觉得还不错，大家可以来试试"
- 合格要点：
  - 先指出两个范围问题：这是分镜脚本不是口播逐字稿，本技能不管；片子已经拍完播出，流失位置要靠后台留存曲线看，不是改稿能定位的
  - 不拿镜号和分镜秒数硬当逐字稿时间轴去标"0:13 划走点"
  - 给出可行的下一步：要么提供纯台词的逐字稿再按流程体检（台词里"非常浓郁醇厚""总之"这些拗口处可以先点名），要么去视频后台看留存曲线定位流失秒数
  - 剪辑卡点、切镜节奏这类问题不越界展开，明确说明那不在本技能范围
- 常见失败：
  - 按镜 1 到镜 4 的时间戳一本正经地标划走点，把分镜表当逐字稿用
  - 大讲剪辑节奏和转场建议，忘了自己只管口播逐字稿
