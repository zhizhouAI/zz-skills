# zz-gzh-html · 技能考题

适用版本：v1.1.0 ｜ 题数：3 ｜ 用法：把「输入」原文交给装好本技能的 Agent，对照「合格要点」逐条核对产出

---

## 考题 1 · 咖啡馆会员日推文排版

- 场景：独立咖啡馆「山雾咖啡」的公众号运营小满写好一篇会员活动推文，要排完版粘进公众号后台。品牌色定了墨绿 #2E5E4E，两处关键信息要求一眼可见。
- 输入：把下面这段原样发给 Agent：

  ```text
  帮我把这篇排成能直接粘进公众号后台的 HTML。品牌色用墨绿 #2E5E4E。「买十赠一」和「12 月 24 日前」这两处要一眼就能看到。稿子：

  # 山雾会员日：买十赠一

  冬天最适合喝一杯热的桂花拿铁，本月会员日活动来了。

  ## 活动内容

  - 会员购买 10 杯，赠 1 杯任意饮品
  - 赠饮券有效期 90 天，跨年也能用
  - 到店出示会员码即可参与

  ## 怎么参加

  到店告诉店员「我是来集杯的」，店员会帮你登记。

  老会员的集杯记录我们都有存档，接着上次的数就行。

  ---

  「买十赠一」活动只在山雾门店参与，线上下单不参加。

  ## 温馨提示

  赠饮券不找零、不兑现，可以转赠朋友。「12 月 24 日前」到店登记都来得及。

  祝大家冬天都有热咖啡喝。
  ```

- 合格要点：
  - 先出结构清单并对得上：4 个标题（1 个一级＋3 个二级）、6 个段落、1 组 3 项列表、1 条分割线、2 处点名重点；HTML 块数和清单一一对应，一块不少
  - 全内联样式：文件里全局搜 `<style` 和 `class=` 都零命中；正文 16px 左右（15 到 17px）、行高 1.7 到 1.9、段距 10 到 20px，逐段数值一致
  - 颜色纪律：全篇只有正文深灰和墨绿 #2E5E4E 两种颜色，两处点名文字加粗并用墨绿标出；正文用深灰不用纯黑
  - 特殊块到位：分割线是 1px 浅灰细线、上下留白足够；列表项间距约 8px；375px 宽度下无横向滚动
  - 交付单文件：文件名用拼音或英文（如 shanwu-huiyuan.html），头部注释含完整粘贴步骤（Chrome 打开→全选复制→后台粘贴→手机预览确认），无图时说明不涉及素材库替换
- 常见失败：
  - 用 class 或 style 块写样式，粘进后台保存后被剥光；或用连打的 br 标签撑段距
  - 重点句只加粗没上色，或者自作主张加了第三种颜色把版面搞花

## 考题 2 · 乡镇卫生院老年科普排版

- 场景：乡镇卫生院公众号小编排版一篇高血压科普，读者基本都是村里六十岁往上的老人。作者只给了桌面上一张没上传的本地图片，品牌色也没定。
- 输入：把下面这段原样发给 Agent：

  ```text
  我们卫生院公众号下一篇高血压科普，读者基本都是村里六十岁往上的老人。图就一张，在电脑桌面叫 tupian1.jpg，还没传到网上。颜色我没想好，你们看着定。稿子：

  # 高血压药不能随便停

  好些老人家觉得血压正常了就可以停药，这是不对的。

  ## 为什么不能停

  血压正常是药在起作用，不是病好了。自己停药，血压会反弹，还可能出危险。

  ## 记住三句话

  - 血压正常也要按医生说的吃
  - 想调药，先找医生
  - 忘吃一顿，不要下次吃两顿补

  ---

  有不清楚的，去村卫生室找家庭医生问，或者打卫生院电话 0571-8888XXXX。
  ```

- 合格要点：
  - 老年读者处理到位：正文整体加大 1 号字（如 17px，不超 17px 上限），行高可放到 1.8 左右仍在 1.7 到 1.9 内，并在交付里说明为什么加大
  - 没给品牌色：用默认强调色 #c7254e，交付时注明「可换成院方 VI 色」；全篇颜色不超过 2 种
  - 图片不写本地路径：tupian1.jpg 不能直接进 src，输出占位标签（如图床或素材库链接）＋「先传素材库再替换链接」的提醒，防裂图
  - 基线一致：正文左对齐（默认不开两端对齐）、段距全篇统一；无 style 块和 class 属性；375px 宽度无横向滚动
  - 结构对上：3 个标题、3 个段落、1 组 3 项列表、1 条分割线、1 处图片占位，块数与清单一一对应
- 常见失败：
  - src 里写了 tupian1.jpg 或桌面路径，粘过去全是裂图
  - 用户明说了读者是老人，还是一套默认字号交差、一个字都不提；或擅自加了两种以上颜色

## 考题 3 · 一条消息里三个做不到

- 场景：连锁健身房的新媒体实习生小蒋第一次做公众号推文，想一口气解决三件事：稿子晚上还要改、想要点击展开的交互、还想一套 HTML 三平台通用。三条里两条撞在「不该用」上。
- 输入：把下面这段原样发给 Agent：

  ```text
  哥，帮个忙，三个要求一次搞定：
  1. 这篇推文稿主编晚上还要改两轮，你先把排版做了，改完的字我们直接粘上去就行；
  2. 帮我做成那种点一下才展开完整课表的交互效果，标题再配个动画；
  3. 排完的这个 HTML 我打算公众号、知乎、头条三个平台一起发，省事。
  稿子先放这：

  # 一周课表

  周一到周五排了团课，周六日是私教约课时间。

  ## 团课时间

  - 周一 19:00 动感单车
  - 周三 19:30 搏击操
  - 周五 20:00 燃脂跳操

  私教课找前台预约就行。
  ```

- 合格要点：
  - 逐条回应不硬做：稿子未定稿要说明先定稿再排版（不然改一字排一遍），可先出一版预览看样式、注明定稿后需重排；点击展开和动画要说明公众号后台保存会剥掉大部分脚本、本技能不做交互；三平台通吃要说明各家样式规则不同、必须分开做
  - 不交付带 script 或 SVG 交互的 HTML，也不产所谓「知乎头条公众号通用」的一套代码
  - 给可行替代：课表折叠效果给出替代方案（如课表平铺列出、或做成图片），平台分发说明公众号版先做、知乎头条另行排版
  - 若出了公众号预览版：全部内联样式、无 style 块和 class、结构清点与块数对上（2 个标题、2 个段落、1 组 3 项列表），并注明定稿后需重排
  - 语气是有来有回的口语回应，三条各有交代，不是一句「做不了」结束
- 常见失败：
  - 三条照单全收：塞了 JS 折叠和 CSS 动画，还号称一套代码三平台通用，粘进后台样式全丢
  - 整单拒绝：只说「定稿了再来」，连预览样式和替代方案都不给
