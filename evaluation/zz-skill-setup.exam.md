# zz-skill-setup · 技能考题

适用版本：v1.1.0 ｜ 题数：3 ｜ 用法：把「输入」原文交给装好本技能的 Agent，对照「合格要点」逐条核对产出

---

## 考题 1 · 常规安装

- 场景：用户刚克隆了 zz-skills 仓库，想把技能装进 Claude Code。
- 输入：帮我把 zz-skills 装到 Claude Code
- 合格要点：
  - 确认来源目录存在（`skills/` 下能看到 zz 技能）再动手
  - 目标目录为 `~/.claude/skills/`，整体复制技能目录而非只复制 SKILL.md
  - 安装完给出可操作的验证步骤（输入 /zz 试一下），而不是只说"装好了"
  - 覆盖同名技能前提醒"会覆盖你本地修改"
- 常见失败：
  - 不确认目标目录就直接往项目目录里装
  - 复制时漏掉技能目录里的附属文件

## 考题 2 · 边界情况（查重与冲突）

- 场景：用户项目里已有一份本地改过的 zz-biz-check，想全量安装最新版。
- 输入：我要更新 zz-skills，但我项目里有个自己改过的 zz-biz-check，别给我弄丢了
- 合格要点：
  - 检出重复入口：同一技能同时存在于全局和项目级时要列出来问用户保留哪份
  - 对用户改过的 zz-biz-check 先备份再更新，不直接覆盖
  - 更新后不允许同名技能留在两个会被同时加载的位置
  - 给出回滚方法（从备份恢复）
- 常见失败：
  - 直接覆盖用户的本地修改且不留备份
  - 装完留下两份同名技能，不管加载顺序

## 考题 3 · 刁钻场景（装到不认识的 Agent）

- 场景：用户用的是一个冷门 Agent，本技能不知道它的技能目录约定。
- 输入：把我装到 Lightning Agent 里，它支持 skills 但我不知道目录在哪
- 合格要点：
  - 承认不知道该 Agent 的目录约定，不硬猜路径
  - 给出通用定位方法：查该 Agent 设置页/文档里的 skills 目录字段，或找已装技能的存放位置反推
  - 用户提供路径后再安装，装完用同样的验证步骤确认
  - 不假装"已安装成功"
- 常见失败：
  - 编造一个不存在的目录路径往里装，还报告成功
  - 拒绝处理，只说"不支持"
