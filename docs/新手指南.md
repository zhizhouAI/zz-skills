# 十分钟上手 zz-skills

## 1. 装技能（2 分钟）

```bash
cd zz-skills
./install.sh --list     # 看看都有什么
./install.sh            # 选个 Agent，装进去
```

## 2. 第一次对话（3 分钟）

装好后打开你的 Agent，输入：

```text
/zz 新手入门
```

调度台会带你过一遍库里的技能，并帮你选一个和你当前处境最相关的试一次。

## 3. 三种常见用法

**直接点名**：已经知道要用什么时，跳过调度台。

```text
/zz-biz-check 我做线下烘焙工作室，月流水 3 万，但算上房租基本不赚
```

**让调度台安排**：事情比较复杂，说不清要用什么。

```text
/zz 我想开始在小红书发内容涨粉，但完全不知道发什么
```

**接着上次干**：上次用过 `zz-save-point` 存档的话。

```text
/zz-continue
```

## 4. 技能是怎么配合的

技能之间传"产物"：比如 `zz-topic-score` 判断选题值得做 → 它的结论直接喂给 `zz-topic-plan` 出方案 → 你照方案写稿 → `zz-risk-line` 逐句查风险 → 发出去。整条链里你只在关键节点拍板。

## 5. 遇到问题

- 技能没被识别：检查目录名和 frontmatter 里的 `name` 是否一致
- 想更新：重新跑一次 `./install.sh`（会覆盖你本地改过的技能，改过先备份）
- 想删掉某个技能：直接删 Agent 技能目录下对应的文件夹
